# 👋 Welcome to ZS Organization(zsorg)

**ZS** is a community-driven, web-based organization focused on uniting developers under one umbrella to build powerful tools, languages, and frameworks that inspire creativity and learning.

---

## 🚀 Our Goals

We’re building an ecosystem of open-source tools and platforms to make development accessible and fun for everyone. Some of our main projects include:

### 🌙 Crescent Framework  
A powerful and flexible framework designed to support our custom languages and services. It’s the foundation of the ZS ecosystem.

### 💻 SharpBasic  
A simple, beginner-friendly programming language that empowers kids (and curious minds of all ages) to build amazing things with code.

---

## 🤝 Join Us!

Want to be a part of our journey?

We welcome contributors of all experience levels. If you're interested in becoming a member of the organization:

1. Visit our repository [**Members**](https://github.com/zs-org/Members).
2. Follow the instructions there to create a pull request.
3. Once approved, you’ll be officially part of ZS!
